# 实际时间看门狗

## 目录结构

```text
watchdog/
└── GameTestWatchdog.hpp # 独立监控线程、绝对期限更新和超时回调
```

## 内部关系与外部依赖

GameTestServer 发布整轮、批次和 tick 中最早的期限；监控线程只读取共享的期限与阶段文字，
调用门面提供的超时处理器。依赖 C++ 标准库，不依赖世界或脚本引擎。

## 容易踩的坑

- 超时处理器不能触碰正在被主线程修改的实例或报告器。
- 已过期的期限不能在下次 arm 时延长，防止监控线程调度延迟掩盖超时。
- 析构唤醒并 join 线程；回调捕获的资源必须活到线程结束。
