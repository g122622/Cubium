# 测试状态监听

## 目录结构

```text
listener/
└── IGameTestListener.hpp  # 单实例结构、开始、完成及重试通知
```

## 内部模块关系

实例在状态变化时按注册顺序通知监听器；监听器连接结果报告、批次推进、可视化和实例拥有的资源清理。

## 上下游外部依赖关系

接口依赖实例前向声明；由 framework 实例调用，runner、minecraft 和 facade 实现具体行为。

## 容易踩的坑

完成通知发生在用户完成回调之后，适合清理测试创建的模拟玩家。跨 tick 引用必须使用实体生命周期引用，清理不能误操作其他测试或真实玩家。
