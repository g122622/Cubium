# 世界光照管理器

## 目录结构树

```text
manager/
└── WorldLightManager.hpp/cpp  # 世界光照查询、维度光照配置与 TLS 引擎获取
```

## 内部模块关系

`WorldLightManager` 经提供者查找区块，读取 nibble 可见侧；天空光 Null 段通过空映射和
上方有效段解释。传播引擎由静态获取入口在线程首次使用时构造，释放入口保留实例供复用。

## 上下游外部依赖关系

- 依赖公共光照类型、区块提供者、区块光照数组和服务端引擎。
- `ServerWorld` 持有管理器，游戏规则读取亮度，光照任务获取引擎，网络回调导出已发布数据。

## 容易踩的坑

- 主线程查询直接访问区块数据，不读取 TLS 引擎的操作缓存。
- TLS 引擎生命周期属于线程；释放入口不销毁实例，也不回收队列高水位。
- Null、全零、未初始化及缺失区块的天空光含义不同，不能只看数组是否为空。
- 当前读路径无锁；原子指针不能消除底层数组原地写入的并发限制。
