# 服务端光照

## 目录结构树

```text
lighting/
├── engine/   # Starlight 天空光、方块光与公共传播实现
└── manager/  # 世界光照读取门面与线程本地引擎获取入口
```

## 内部模块关系

`WorldLightManager` 提供光照查询与 TLS 引擎访问。生成、加载和运行时任务取得线程本地引擎，
经区域调度保证重叠光照写操作串行。引擎每次操作建立空间缓存，结束后清除缓存引用；
区块自身持有光照数组与空映射。

## 上下游外部依赖关系

- 依赖 common 中的光照类型、提供者接口、方块形状、区块数据及光照数组。
- `ServerWorld` 提供世界与区块访问；生成、加载和运行时光照任务驱动传播。
- 网络和游戏规则通过已发布数据读取光照，更新通知交回主线程处理。

## 容易踩的坑

- 区域调度保证单写者，不自动保证可见数组与主线程并发读取时无数据竞争。
- 引擎不持有区块的长期共享所有权；TLS 队列和缓存容量在线程退出前仍可能保留。
- 段去初始化与整个区块卸载不同；方块光 Hidden 保留减亮计算需要的数据。
- 天空光 Null 需要空映射和向上回溯，不能一律返回 0 或 15。
