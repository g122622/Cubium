# 外来存档读取

## 目录结构

```text
reader/
└── java/ # Java Anvil 区域、列、段和世界元数据读取
```

## 内部模块关系

世界读取器管理区域文件，列读取器分派段数据和元数据；方块与群系映射器将外来标识转换为内部值。

## 上下游外部依赖关系

上游为存储后端，下面依赖区域文件、NBT、压缩和内部区块数据模型。

## 容易踩的坑

- 区域读取须验证坐标和完成状态，NBT 根标签前缀须在入口解包。
- 方块状态和群系必须按完整名称映射，不能用未注册值静默掩盖映射缺口。
- 段数据使用带填充的 long 位压缩，不能把尾部空位作为下一段索引位。
