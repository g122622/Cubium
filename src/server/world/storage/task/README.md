# 存储任务

## 目录结构树

```text
task/
├── StorageTask.hpp/cpp           # 存储任务、执行器与取消收尾
├── StorageTaskManager.hpp/cpp    # 外部线程池的存储任务提交与取消门面
└── README.md                    # 任务生命周期约束
```

## 内部模块关系

StorageTask 持有执行器。StorageTaskManager 向外部 UniversalWorkerPool 提交任务，自身不拥有线程池。

## 上下游外部依赖关系

- 上游为单存档存储门面和段批次保存。
- 下游依赖公共任务接口、线程池、存储键及追踪宏。

## 容易踩的坑

- 执行器的取消分支必须结清结果和请求计数，不得进行 I/O。
- 池拒绝提交时在任务销毁前同步触发失败回调；提交门面须补调 onCancel，避免请求永远无法完成。
- 已执行或已由 worker 取消的任务不能再次执行取消收尾。
- 关闭存档只等待该存档请求，不能等待共享池中的无关任务。
