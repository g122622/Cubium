# 导航点同步

## 目录结构

```text
waypoint/
├── WaypointManager.hpp # 每维度导航点门面及接收快照
└── WaypointManager.cpp # 范围、可见性、表示选择及增量同步
```

## 内部模块关系

ServerWorld 持有门面，实体 tick 后按接收玩家维护已成功发送的快照。位置使用精确方块、区块或远距离方位角，表示或图标变化重新 Track。

## 上下游外部依赖关系

依赖生物属性、物品/效果、队伍颜色、玩家区块视图和连接发送。服务器 tick、维度离场和登录重配置调用门面；IR codec 负责 UUID/字符串标识、RGB 及四种位置表达。

## 容易踩的坑

- 客户端 Update 只更新同类型位置；类型、样式或颜色变化必须 Track。
- 范围由发送端与接收端取小值，旁观接收端可绕过距离和源旁观状态限制。
- 潜行、隐身效果和头部遮挡物停止发送；规则关闭和接收范围清零要 Untrack 旧快照。
- 跨维度前清除旧维度连接；重配置清除接收快照，下一 tick 完整重发。
- 远距离只传方位角，RGB 颜色是三个字节，不能写成四字节整数。
