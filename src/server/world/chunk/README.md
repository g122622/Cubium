# chunk 模块

## 目录结构树

```text
chunk/
└── pipeline/  # 区块生成阶段、依赖与推进约束
```

## 内部模块关系

各文件承接目录树中标明的单一职责，通过同领域接口组合。独占的辅助实现位于使用者目录下。

## 上下游外部依赖关系

公共层提供领域类型与接口；服务端通过应用装配连接玩家、网络和世界实现。源文件的构建归属与领域目录一致。

## 容易踩的坑

- 目录按领域职责组织；跨领域协作通过明确入口和基础类型。
- 新增或迁移源文件时同步更新所有消费目标的 CMake 清单。

- 阶段可用必须同时满足区块对象存在和已完成状态达标；初始 EMPTY 状态不代表已经加载空区块。
- 依赖图操作由调度区域锁串行化；每个步骤的邻居半径不得超过最大访问半径，递归调度入口覆盖两倍最大访问半径。
- 邻居保活从依赖扫描开始，持续至完成、取消、失败或需求撤销；就绪的邻居也必须保留，否则等待期间卸载会不断重建依赖。
- 取消信号不能提前清除活跃任务身份。执行器确认退出后按原任务身份结清，卸载前必须在同一调度锁内重新检查安全性。
- 低阶段请求在其阶段完成后即可交付，不能等待高阶段任务；高阶段取消后仍须交付已经就绪的请求。
