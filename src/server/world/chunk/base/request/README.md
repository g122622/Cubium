# 阶段请求和优先级规则

## 目录结构树

```text
request/
├── ChunkRequestPriority.hpp  # 加载级别、阶段与执行优先级映射
└── ChunkRequestWaiter.hpp  # 一个阶段请求的回调和 promise 交付端
```

## 内部模块关系

等待者保存阶段目标和交付端；优先级规则显式映射为通用计算池档位。

## 上下游外部依赖关系

由 holder、生命周期协调、来源加载和生成调度消费；依赖阶段规则和公共数据声明。

## 容易踩的坑

- 异步保存目标必须引用稳定的阶段表元素。低阶段请求达到自己的目标即可交付，不等待更高阶段任务。
- 迁移源文件时同步更新全部消费目标的包含路径与唯一 CMake 编译归属。
