# 加载票据、距离传播和玩家追踪

## 目录结构树

```text
demand/
├── base/  # 跨能力共享的值类型与交接协议
├── ChunkDemandController.cpp  # 汇总票据与玩家来源并维护追踪集合
└── ChunkDemandController.hpp  # 汇总票据与玩家来源并维护追踪集合
```

## 内部模块关系

票据与玩家来源共同更新距离图；玩家追踪范围独立决定发送对象和模拟查询。

## 上下游外部依赖关系

由区块门面和内部生命周期模块消费；依赖本目录 base 的票据、级别、距离图及公共坐标。

## 容易踩的坑

- 距离传播有预算，一次推进不保证收敛。请求视距和服务端上限分别保存；加载距离不能替代模拟距离。冷却票据只保留现有 holder，不能重新触发生成。
- 迁移源文件时同步更新全部消费目标的包含路径与唯一 CMake 编译归属。
