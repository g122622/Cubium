# 跨能力共享的值类型与交接协议

## 目录结构树

```text
base/
├── ChunkDistanceGraph.cpp  # 加载来源的距离级别传播
├── ChunkDistanceGraph.hpp  # 加载来源的距离级别传播
├── ChunkLoadLevel.hpp  # 加载、模拟和生成级别定义
└── ChunkLoadTicket.hpp  # 票据值、类型及单坐标票据集合
```

## 内部模块关系

本目录组织依赖链末梢的值类型与工具，由所属能力模块复用。

## 上下游外部依赖关系

依赖公共坐标、类型和标准库；由所属区块能力消费。

## 容易踩的坑

- 基础文件不能反向访问门面、世界或生命周期控制器。
- 迁移源文件时同步更新全部消费目标的包含路径与唯一 CMake 编译归属。
