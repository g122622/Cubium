# 候选回收、异步保存和最终退场复核

## 目录结构树

```text
unloading/
├── ChunkUnloadController.cpp  # 管理保存、复核、候选、冷却与重试
└── ChunkUnloadController.hpp  # 管理保存、复核、候选、冷却与重试
```

## 内部模块关系

安全性变化登记候选，主线程按预算开始保存；保存完成后复核身份、当前需求、脏状态和邻居保活。

## 上下游外部依赖关系

依赖注册表、需求、生成、来源与世界退场协议；存储内部自行结清在途保存。

## 容易踩的坑

- 保存失败须恢复脏状态；保存后再次变脏或出现新需求则中止退场。无脏数据也延后接收一次完成消息；不安全时用最弱生成级别冷却。
- 迁移源文件时同步更新全部消费目标的包含路径与唯一 CMake 编译归属。
