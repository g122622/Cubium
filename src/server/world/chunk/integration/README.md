# 区块接入世界的激活、光照与退场

## 目录结构树

```text
integration/
├── WorldChunkLifecycle.cpp  # 主线程世界激活、后处理和退场接入
```

## 内部模块关系

WorldChunkLifecycle 实现世界交接协议，主线程执行实体接入、tick 注册和后处理；生成光照回调受区域执行资格保护。

## 上下游外部依赖关系

依赖 ServerWorld、注册表、需求查询、光照引擎和生成光照提供者；由控制器装配。
