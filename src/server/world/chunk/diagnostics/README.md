# 状态和内存诊断快照

## 目录结构树

```text
diagnostics/
├── ChunkDiagnostics.cpp  # 按注册表快照采集诊断信息
├── ChunkDiagnostics.hpp  # 按注册表快照采集诊断信息
└── ChunkDiagnosticSnapshot.hpp  # 单个生命周期实例的只读诊断值
```

## 内部模块关系

诊断使用注册表提供的保活列表采集状态，不参与需求和调度。

## 上下游外部依赖关系

由区块门面及性能分析消费；依赖注册表和 primer 只读查询。

## 容易踩的坑

- 采集 primer 内存信息前须暂停生成写入。保活列表只保证对象存活，不是内容不可变快照。
- 迁移源文件时同步更新全部消费目标的包含路径与唯一 CMake 编译归属。
