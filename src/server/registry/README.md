# 服务端注册表装配

## 目录结构

```text
registry/
├── RegistryBootstrap.hpp  # 注册表启动装配门面
└── RegistryBootstrap.cpp  # 注册、数据包加载与依赖顺序
```

## 内部模块关系

装配门面按引用顺序初始化方块、物品、世界生成、实体及标签，准备登录注册表快照和协议编号映射。

## 上下游外部依赖关系

依赖公共注册表、数据包仓库和服务端网络注册表构建器；服务器启动流程调用本门面。

## 容易踩的坑

- 注册表条目的标签须在其条目注册后加载。
- 登录 NBT 的附魔效果会展开物品、实体类型和伤害类型标签；提前构建并缓存会永久保留未解析的标签引用。
- 数据包切换时重新注册来源并重建登录快照，避免继续发送旧数据。
