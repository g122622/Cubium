# 方块身份、状态容器与行为扩展入口

## 目录结构树

```text
core/
├── Block.cpp  # 模块接口与实现
└── Block.hpp  # 方块基类
```

## 内部模块关系

Block 持有身份、状态容器和注册属性，子类覆盖行为；地图颜色解析策略由 BlockRegistry 绑定，核心模型不依赖原版注册快照。

## 上下游外部依赖关系

上游为 properties、state、physics 与世界接口；下游为具体方块、物品交互、实体和世界模拟。

## 容易踩的坑

- 方块和状态由注册表持有，发放的引用必须保持稳定。
- 形状工厂显式区分 box 的归一化坐标和 fromPixelBox 的像素坐标。
- 声音事件标识、方块族规则、LevelEventId 与模拟 GameEvent 分别管理。
- 原版地图颜色策略在注册时绑定，公共模型不直接引用原版快照。
