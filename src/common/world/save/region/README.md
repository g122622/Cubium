# Region 文件系统 (Region)

实现 Minecraft 的 Region 文件格式（.mca），用于存储区块数据。

## 文件说明

| 文件 | 职责 |
|------|------|
| `RegionFile.hpp/cpp` | 单个 .mca 文件操作，读写区块数据 |
| `RegionFileCache.hpp/cpp` | Region 文件缓存，LRU 策略管理打开的文件 |
| `RegionBitmap.hpp/cpp` | 扇区分配位图，跟踪文件空间使用 |
| `CompressionType.hpp/cpp` | 压缩类型枚举（GZIP、Zlib、无压缩） |

## Region 文件格式

```
┌─────────────────────────────────────────────────────────────┐
│  Header (8192 bytes)                                        │
│  ┌─────────────────────────────────────────────────────────┐│
│  │  Offset Table (4096 bytes) - 1024 entries × 4 bytes    ││
│  │  每个条目：offset(24bit) + sectorCount(8bit)            ││
│  └─────────────────────────────────────────────────────────┘│
│  ┌─────────────────────────────────────────────────────────┐│
│  │  Timestamp Table (4096 bytes) - 1024 entries × 4 bytes ││
│  │  每个条目：Unix时间戳（秒）                              ││
│  └─────────────────────────────────────────────────────────┘│
├─────────────────────────────────────────────────────────────┤
│  Chunk Data Sectors                                         │
│  每个区块：长度(4B) + 压缩类型(1B) + 压缩的NBT数据           │
└─────────────────────────────────────────────────────────────┘
```

## 区块定位

```cpp
// 从 ChunkPos 计算 Region 内索引
u32 index = (chunkX & 31) + (chunkZ & 31) * 32;  // 0-1023

// 从 Region 文件名解析
// r.<regionX>.<regionZ>.mca
i32 regionX = chunkX >> 5;  // chunkX / 32
i32 regionZ = chunkZ >> 5;  // chunkZ / 32
```

## 压缩类型

| 值 | 类型 | 说明 |
|----|------|------|
| 1 | GZIP | GZIP 压缩 |
| 2 | Zlib | Zlib (Deflate) 压缩，最常用 |
| 3 | Uncompressed | 无压缩 |
| 128+ | External | 外部文件 (.mcc) |

## LRU 缓存策略

`RegionFileCache` 使用 LRU 策略管理打开的文件：
- 默认最大缓存 256 个文件
- 访问时更新 LRU 顺序
- 超出限制时关闭最久未使用的文件

## 容易踩的坑

1. **大区块处理**：超过 1MB 的区块需要存储到外部 .mcc 文件
2. **字节序**：头部数据使用大端序（网络字节序）
3. **文件同步**：写入后需要同步到磁盘，防止数据丢失
4. **缓存一致性**：写入后需要更新缓存中的数据
