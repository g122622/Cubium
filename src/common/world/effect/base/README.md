# 本领域共享的基础类型与定义

## 目录结构树

```text
base/
└── LevelEventId.hpp  # 客户端预定义世界效果编号；模拟事件使用 GameEvent，独立声音使用 SoundEvents。
```

## 内部模块关系

LevelEventId 只定义客户端预置效果编号。世界与广播接口传递强类型，构造网络 IR 时显式转为整数；它与模拟 GameEvent、独立 SoundEvents 分开。

## 上下游外部依赖关系

方块、实体、物品与唱片机发起效果；ServerWorld 回调交给网络广播，Java 客户端负责实际声音、粒子和动画。

## 容易踩的坑

- 目录按领域职责组织；跨领域协作通过明确入口和基础类型。
- 新增或迁移源文件时同步更新所有消费目标的 CMake 清单。
