# 图片编解码

## 目录结构

```text
image/
└── StbImage.cpp  # stb_image 与 stb_image_write 的唯一 PNG 编解码实现
```

## 内部模块关系

实现直接编入 `mc_common`，通过 STB 的既有 C 接口提供 PNG 解码与编码。

## 上下游外部依赖关系

依赖 vcpkg 的 `stb` 头文件；公共皮肤加载、校验及客户端纹理模块通过公共库复用其符号。

## 容易踩的坑

- 其他翻译单元只包含 STB 声明，不能再次定义两个 implementation 宏。
- PNG 支持限定保持在本文件；服务端不能靠链接客户端图集间接获得编解码实现。
- 仅此第三方实现单元关闭警告，不放宽公共模块其他代码的编译门禁。
