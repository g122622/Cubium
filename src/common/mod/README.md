# 兼容模组

## 目录结构树

```text
mod/
├── bedrock/  # 基岩行为包与脚本接口兼容实现
└── README.md # 模组层依赖与对象生命周期约束
```

## 内部模块关系

`bedrock/addon` 管理脚本运行时、模块绑定和自定义组件，通过公共实体与世界接口接入游戏行为。

## 上下游外部依赖关系

服务端注册并驱动兼容模组，本目录依赖公共实体、世界、资源和物品类型。服务端专属 GameTest 绑定位于 `server/test`，公共模组不依赖服务端代码。

## 容易踩的坑

- 脚本对象与游戏实体的生命周期独立，非拥有实体句柄在实体析构前失效；所有权移交保留句柄，避免跨维度迁移后丢失同一实体的引用。
- 实体编号由各维度独立分配，进程级句柄管理须使用实际对象身份。
