# 基岩兼容层

## 目录结构树

```text
bedrock/
├── addon/    # 行为包加载、脚本引擎、模块绑定与自定义组件
└── README.md # 兼容层依赖与生命周期约束
```

## 内部模块关系

`addon` 通过引擎无关的脚本接口组织 QuickJS 后端、模块绑定和组件注册。

## 上下游外部依赖关系

服务端调用本层运行行为包；本层依赖公共游戏类型与资源包基础设施，服务端专属绑定由服务端注册。

## 容易踩的坑

- 实体脚本句柄不拥有游戏实体，须通过绑定层的句柄注册表处理失效。
- 不同世界可拥有同号实体，实体编号不能作为进程级失效注册表的唯一键。
