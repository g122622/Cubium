# 基岩行为包与脚本运行时

## 目录结构树

```text
addon/
├── core/        # 引擎、运行时、上下文与模块描述抽象
├── engine/      # QuickJS 后端与模块加载
├── binding/     # 值句柄、类型注册、对象包装和生命周期
├── modules/     # Minecraft 脚本模块绑定
├── content/     # 行为包内容与实体持久状态
├── component/   # 方块和物品自定义组件回调
├── plugin/      # 脚本插件实例与执行分组
├── pack/        # 行为包清单、资源读取和依赖
├── event/       # 同步前置与排队后置事件
├── lifecycle/   # 初始化、tick、调度与关闭
├── diagnostics/ # 诊断及日志
└── CMakeLists.txt # 公共 addon 库构建入口
```

## 内部模块关系

ScriptManager 统一管理包、插件、引擎、事件和调度。原生模块仅通过绑定抽象操作脚本值；插件上下文独立管理模块来源、类原型和持久引用。

## 上下游外部依赖关系

服务端脚本门面驱动本目录，服务端专属模块从外部注入。公共 addon 库依赖公共世界、实体、物品与资源设施，不依赖客户端或服务端实现。

## 容易踩的坑

- 清单解析成功、脚本入口执行成功和完整内容兼容是不同验收条件，不能依据加载日志宣称行为包完整可用。
- 只有 engine/ 可以包含 QuickJS 头文件，其他层必须经 IScriptBindingContext 使用值、回调及类。
- 同一引擎内的插件共享运行时，源码加载器和类注册表必须按上下文隔离。
- 释放插件上下文前清理外部回调及引用；实体失效通过实际对象身份通知其脚本包装对象。
