# 脚本属性绑定

## 目录结构树

```text
properties/
├── ScriptPropertyValue.hpp/cpp # 脚本标量、Vector3 转换和异常传播
└── ScriptDynamicPropertiesBinding.hpp/cpp # 动态属性方法注册与所有者解析
```

## 内部模块关系

通用动态属性绑定先转换并校验参数，再通过注入的访问器解析所有者，成功操作后调用提交入口。实体与世界直接使用所属容器，物品提交独立快照。

## 上下游外部依赖关系

World 模块和 Entity 属性绑定复用本目录，依赖引擎无关绑定上下文与公共属性容器。

## 容易踩的坑

- 属性 getter 和 Proxy 枚举会执行脚本并抛出异常，写入前必须检查并重新抛出原异常。
- 数组需要由 getType 明确区分，不能作为普通属性批次对象接受。
- 所有者访问器必须校验接收者和对象寿命；回调持有的世界状态不得依赖局部工厂对象。

- 参数转换完成后才解析属性所有者，避免 getter 重入导致物品快照过期或实体引用失效。
