# 基岩伤害原因

## 目录结构树

```text
damage/
└── BedrockDamageCause.hpp/cpp # 原生伤害类型与脚本、JSON 原因名称转换
```

## 内部模块关系

统一映射表提供脚本伤害原因名称和反向解析，JSON 过滤器名称从同一映射生成。

## 上下游外部依赖关系

由实体过滤器与服务端脚本事件桥接调用；依赖公共伤害类型和基础字符串类型。

## 容易踩的坑

- 脚本原因使用驼峰名称，JSON 过滤器使用下划线名称；普通近战在脚本中为 entityAttack，在 JSON 中为 attack。
- fatal 表示本次伤害的致死结果，不是独立的原生伤害类型，也不能仅凭实体当前生命值推断。
