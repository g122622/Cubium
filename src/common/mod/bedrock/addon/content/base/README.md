# 行为包内容基础类型

## 目录结构树

```text
base/
├── damage/ # 原生伤害与脚本、JSON 原因名称映射
└── properties/ # 按包隔离的动态属性和值编码
```

## 内部模块关系

properties 为实体和世界提供共用属性容器，不持有游戏对象或脚本上下文。damage 统一脚本事件和 JSON 过滤器的伤害类型映射。

## 上下游外部依赖关系

由实体状态组件、脚本门面和属性绑定使用，依赖公共 Result 与 JSON 类型。

## 容易踩的坑

- 数据由所属对象持有，包 UUID 只是访问作用域，不能以进程单例保存所有世界状态。
