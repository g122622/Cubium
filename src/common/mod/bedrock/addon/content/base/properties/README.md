# Addon 属性基础类型

## 目录结构树

```text
properties/
├── AddonDynamicProperties.hpp/cpp # 包作用域动态属性、校验与脏标记
└── AddonPropertyValue.hpp/cpp # 属性值类型校验与持久化编码
```

## 内部模块关系

动态属性容器使用属性值工具校验写入、编码快照和原子恢复。实体声明属性共用编码，以保留 NBT 布尔类型。

## 上下游外部依赖关系

实体状态和世界脚本门面拥有容器；通用属性绑定读写容器。依赖 Result 与 JSON，不访问文件或引擎。

## 容易踩的坑

- null 表示删除，不作为持久化值存储。
- 批量写入和恢复先完整校验；失败不能改变数据或清除脏标记。
- 快照生成不清除脏标记，只有存储成功才确认保存。
- 所有调用在脚本所属游戏线程执行，不与异步保存线程共享可变容器。
