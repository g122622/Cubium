# Molang 语法

## 目录结构树

```text
syntax/
├── MolangProgram.hpp # 节点类别、节点索引与程序结构
└── MolangParser.cpp # 词法、优先级解析、函数签名和预算校验
```

## 内部模块关系

解析器将输入拆为有界 token 序列，按运算符优先级构造索引节点，并校验函数名称、参数数量及语法树深度。

## 上下游外部依赖关系

由表达式门面调用，生成的程序交给 eval 求值，依赖 Molang 基础类型和 Result。

## 容易踩的坑

- 名称不区分大小写，字符串内容不能随名称一起转小写。
- q. 与 query. 使用同一查询名称；冒号在字符串内不参与条件语法。
- 左结合链也可能形成深层语法树，不能只限制解析函数递归深度。
