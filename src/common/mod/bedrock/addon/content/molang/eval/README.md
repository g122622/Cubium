# Molang 求值

## 目录结构树

```text
eval/
└── MolangEvaluator.cpp # 短路运算、属性查询、数学函数与宿主随机数
```

## 内部模块关系

求值器遍历不可变节点，通过宿主读取声明属性；数学运算使用公共数学工具，随机函数使用宿主注入的随机源。

## 上下游外部依赖关系

由表达式门面调用，依赖 syntax 节点、基础值类型、随机接口、数学工具与日志出口。

## 容易踩的坑

- 除数为零的除法和取模返回零，不能让非有限值进入实体属性。
- math.random_integer 的有符号全区间不能用 i32 差值计算区间长度。
- 缺失声明属性的 property 查询产生内容警告并返回零，has_property 则直接返回零。
