# Molang 表达式

## 目录结构树

```text
molang/
├── MolangExpression.hpp/cpp # 编译和求值的统一门面
├── base/ # 数值、字符串与宿主访问上下文
├── syntax/ # 有界表达式解析和不可变节点程序
└── eval/ # 运算、属性查询与数学函数求值
```

## 内部模块关系

门面调用 syntax 生成可共享的不可变程序，eval 使用每次调用显式提供的属性读取和随机源求值。数值使用单精度，字符串保留原始大小写。

## 上下游外部依赖关系

实体事件程序编译并复用本目录表达式，求值时注入当前已生效属性和实体随机源。依赖公共 Result、数学工具和随机数接口，不依赖脚本引擎。

## 容易踩的坑

- 三角函数使用角度，数值运算使用单精度，不能套用 JavaScript 的数值和角度语义。
- 逻辑与条件运算必须短路，未选分支不能读取属性或推进随机源。
- 已编译程序不得缓存某个实体的属性值，宿主上下文按调用提供。
- 未支持的语法或函数明确返回错误；节点数量和深度均受限。
