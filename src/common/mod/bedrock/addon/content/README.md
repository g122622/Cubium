# 行为包内容

## 目录结构树

```text
content/
├── AddonContentManager.hpp/cpp # 行为包内容验证、注册和批次撤销
├── base/ # 属性校验、包作用域容器与类型编码
├── entity/ # 数据驱动实体定义与实例状态
└── item/ # 基于物品 custom_data 的属性读写
```

## 内部模块关系

AddonContentManager 按包优先级收集、校验和注册实体定义。实体内容层持有声明属性和按包隔离的动态属性，脚本绑定通过实体 ECS 组件访问实例状态。

## 上下游外部依赖关系

由脚本模块和公共实体生命周期调用，依赖公共实体、资源标识和 NBT 设施。

## 容易踩的坑

- 声明属性延迟到实体 tick 生效，动态属性即时生效。
- 包身份使用清单 UUID，同名动态属性不能跨包共享。

- 定义全部验证通过后才注册类型；脚本加载失败仅撤销本批新增内容。
