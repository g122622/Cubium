# 物品 Addon 状态

## 目录结构树

```text
item/
└── ItemAddonProperties.hpp/cpp # 物品动态属性与 custom_data 组件之间的读写门面
```

## 内部模块关系

ItemAddonProperties 使用公共动态属性容器校验快照，通过 ItemStack 已有自定义数据接口保存类型编码。

## 上下游外部依赖关系

由 ItemStack 脚本绑定调用，依赖公共物品和属性基础类型；拷贝、容器、NBT 和网络组件序列化沿用物品原有链路。

## 容易踩的坑

- 写入只适用于最大堆叠数为一的物品，不能仅根据当前数量判定。
- 不维护外部对象状态表，动态属性随物品值复制。
- 清空最后一个包的属性时移除属性标签，保留其他 custom_data。
- 已保存的属性损坏时返回失败，不能按空表继续覆盖。
