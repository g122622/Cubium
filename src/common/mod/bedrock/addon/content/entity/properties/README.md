# 实体属性定义

## 目录结构树

```text
properties/
├── EntityPropertyDefinitions.hpp/cpp # 属性声明验证、默认表达式编译和逐实例初始化
└── EntityPropertyValue.hpp/cpp # Molang 结果类型转换与实体属性数值限幅
```

## 内部模块关系

定义层先编译默认表达式并验证属性类型与范围，实例创建时求出实际默认值。事件程序共用数值限幅和类型转换，状态组件接收实际声明与值。

## 上下游外部依赖关系

由实体定义工厂和事件程序调用，依赖 Molang 门面与 EntityAddonState 的属性校验。

## 容易踩的坑

- 加载阶段不能求出并缓存随机默认值，默认表达式在每个实例上单独求值。
- 默认表达式不能读取尚未建立的实体属性，即使查询位于未选条件分支也应拒绝。
- 枚举默认字符串若已列在 values 中就是字面量，不能把 true 等枚举项误当数值表达式。
- 类型占位只供静态声明验证，不能暴露为实际实例的默认值。
- 保存属性在恢复阶段覆盖实例默认值，不能在 NBT 加载之后重新初始化默认值。
