# 实体内容

## 目录结构树

```text
entity/
├── query/ # 活动组件、原生装备、归属和变种的统一查询
├── filters/ # 逻辑组合、主体选择和类型化实体条件
├── events/ # 数据驱动事件程序、实例入口与触发通知
├── properties/ # 属性声明、逐实例默认值和 Molang 类型转换
├── definition/ # 实体 JSON、基础组件及实例工厂
└── state/ # 实体属性、待应用写入与存档编码
```

## 内部模块关系

definition 验证实体定义并在实例工厂安装组件、属性与事件程序；state 作为 ECS 扩展组件保存每个实体的 addon 数据，与实体共同销毁。

## 上下游外部依赖关系

实体 tick 应用声明属性；脚本 Entity 绑定读写属性；统一组件序列化注册表保存和恢复状态。

## 容易踩的坑

- 恢复声明属性之前先安装对应实体定义。
- 状态属于实体实例，不能用实体编号建立进程级数据表。
