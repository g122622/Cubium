# 实体属性状态

## 目录结构树

```text
state/
└── EntityAddonState.hpp/cpp # 声明属性、包作用域动态属性及实体 NBT 序列化
```

## 内部模块关系

EntityAddonState 校验声明和值，声明写入进入待应用队列，动态属性按包 UUID 分组。组件序列化函数将快照接入统一 NBT 注册表。

## 上下游外部依赖关系

脚本 Entity 属性绑定、Entity::tick 和组件序列化器消费本组件，组件依赖 Result、资源标识与 NBT 转换设施。

## 容易踩的坑

- 保存应包含合法的待应用写入，但不能因此提前改变本 tick 可见值。
- NBT Byte 不能区分布尔和数字，持久化必须保留显式类型标记。
- 定义替换、批量动态写入和快照恢复先完整校验，失败时保留已有数据。
