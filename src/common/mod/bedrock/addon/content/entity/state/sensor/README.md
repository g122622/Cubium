# 实体环境传感器

## 目录结构树

```text
sensor/
└── EntityEnvironmentSensor.hpp/cpp # 环境触发器编译、事件引用验证与逐 tick 求值
```

## 内部模块关系

传感器持有已编译事件引用，实体每次更新后按定义顺序读取当前状态并触发事件；实例组件负责随活动组安装和移除传感器。

## 上下游外部依赖关系

实体定义层执行输入和引用校验，AddonEntityComponents 驱动执行；依赖公共实体、过滤器和事件程序。

## 容易踩的坑

- 触发器字段支持单对象和对象数组，数组中的匹配事件都按顺序执行。
- 同一 tick 的后续触发器不能看见前一事件尚未应用的属性或组件组变化。
- 条件持续满足会继续触发；传感器没有边沿去重状态，因此保存活动组件来源即可恢复。
