# 实体计时器

## 目录结构树

```text
timer/
└── EntityTimerState.hpp/cpp # 时长选择、tick 倒计时、到期事件和状态保存
```

## 内部模块关系

计时器验证固定、区间或加权时长，组件激活时选择初始间隔。到期后先切换停止或下一轮状态，再通过 EntityEventTrigger 触发实体事件。

## 上下游外部依赖关系

AddonEntityComponents 管理计时器激活、移除和保存；实体定义层验证事件引用。依赖公共随机源、tick 常量和组件事件入口。

## 容易踩的坑

- 实体本次更新结束后触发到期事件，其属性和组件组修改在后续 tick 边界应用。
- 重复添加计时器所在组需要重新开始倒计时，移除组应立即停止后续计时。
- 保存剩余 tick 和本次间隔，恢复时不能重新从完整时长开始。
- 单次计时器的停止状态也要保存，不能因为组件仍存在而重新触发。
- randomInterval 为 false 时重复使用激活时选出的间隔；加权选择不得选中零权重项。
