# 原版家族基础数据

## 目录结构树

```text
base/
└── VanillaEntityFamilies.hpp/cpp # 官方基础定义中稳定家族的只读查找
```

## 内部模块关系

只读表按实体标识排序，查询区分已知类型的不匹配和缺失元数据。实体过滤器先读取 addon 活动家族，再查询本表。

## 上下游外部依赖关系

数据来源于官方文档随附的 Reference/Source/VanillaBehaviorPack/entities 基础组件，由实体过滤器使用；运行时不访问开发机上的文档目录。

## 容易踩的坑

- 有不同组件组家族配置的类型不进入静态表，不能把条件家族当作始终活动的家族。
- 返回空值表示缺失或动态状态需要额外解析，不能直接当作 false。
- 已知类型没有指定家族时返回 false，允许正常处理不等比较。
- 更新数据时维持实体标识排序，不从 Java 类名补造家族。
