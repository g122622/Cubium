# 脚本事件总线

## 目录结构树

```text
event/
├── ScriptEventData.hpp/cpp   # 跨上下文事件值快照与受追踪的对象引用
├── ScriptEventBus.hpp/cpp    # 总线初始化、前置分发与后置刷新
├── BeforeEventSignal.hpp/cpp # 同步前置回调与取消结果汇总
└── AfterEventSignal.hpp/cpp  # 后置事件排队与批量分发
```

## 内部模块关系

ScriptEventBus 拥有前置和后置信号。前置分发汇总每个回调的取消结果，后置分发取出当前批次并依次调用订阅者。

## 上下游外部依赖关系

ScriptManager 管理总线生命周期；脚本模块建立订阅；服务端 EventBridge 发布游戏事件。本目录依赖公共基础类型与标准库。

## 容易踩的坑

- 分发时复制订阅快照，回调在锁外执行，允许回调中修改订阅及排队新事件。
- 前置回调返回是否取消；即使此前已有回调取消，仍继续通知剩余订阅者。
- 后置回调新排队的事件属于下一批次，不能在持锁遍历当前事件队列时直接执行。
- 脚本回调必须在所属游戏线程执行；互斥锁不保证游戏对象的跨线程生命周期。

- 排队载荷使用 ScriptEventData，物品和字符串保存副本，实体引用通过生命周期注册表失效；禁止在排队事件中保存调用栈上的临时地址。
