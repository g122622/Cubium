# 分阶段包定义

## 目录结构

```text
packets/
├── handshake/      # 连接意图
├── status/         # 服务器状态查询
├── login/          # 登录协商
├── configuration/  # 注册表与客户端配置
└── play/           # 游戏阶段数据
```

## 内部模块关系

各目录声明 plain struct；上级 IrPacket.hpp 将其组合为阶段变体。

## 上下游外部依赖关系

依赖公共值类型；协议后端负责线格式，客户端和服务端业务负责消费。

## 容易踩的坑

- 新包追加到阶段变体，并同步协议表下标。
- 不在 IR 内引入客户端或服务端专属对象。
