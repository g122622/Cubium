# 收纳袋

## 目录结构

```text
bundle/
├── BundleContents.hpp/cpp # 内容物、重量和瞬态选择
└── BundleItem.hpp/cpp     # 使用、槽位交互与内容物操作
```

## 内部模块关系

BundleItem 使用 BundleContents 的可变构建器完成插入、选择和取出，再写回 ItemStack。

## 上下游外部依赖关系

依赖 ItemStack、Slot、Player 和世界掉落接口；菜单点击与入站选择处理器调用本模块，数据组件边界将内容物转换为现代 bundle_contents 列表。

## 容易踩的坑

- 选择包的槽号是当前菜单槽号，不能当作玩家背包内部下标，也不支持光标槽号。
- 选择索引 -1 清除；重复索引会切换为未选择。选择不进入网络组件或存档。
- 自动菜单更新应按槽下发，避免全量覆盖其他收纳袋的客户端瞬态选择。
- 嵌套收纳袋重量包含内部物品和固定基础重量；反序列化重新计算重量。
- 内容组件是 ItemStack 列表，网络嵌套解码有深度上限。
