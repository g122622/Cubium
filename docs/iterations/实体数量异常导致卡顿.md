进入游戏之后，观察到大量的实体生成（实体数量不断攀升，且似乎没有上限）。

通过下面查询语句查询perfetto：

```sql
WITH events AS (
    SELECT
        dur,
        EXTRACT_ARG(arg_set_id, 'debug.name') AS debug_name
    FROM slice
    WHERE name = 'EntityManager::tick.perEntity'
)
SELECT
    debug_name,
    COUNT(*) AS event_count,                -- 事件总数
    AVG(dur) / 1e6 AS avg_duration_ms,      -- 平均耗时（转换为毫秒）
    MIN(dur) / 1e6 AS min_duration_ms,      -- 最短耗时
    MAX(dur) / 1e6 AS max_duration_ms,      -- 最长耗时
    SUM(dur) / 1e6 AS total_duration_ms     -- 总耗时
FROM events
WHERE debug_name IS NOT NULL                -- 排除空值
GROUP BY debug_name
ORDER BY event_count DESC;                  -- 按数量从多到少排序
```
