## 容易踩的坑

- 历史测量、静态字段推导和未落地方案应分别标注，不能将预测写成实测收益。
- 复用数字前核对提交、平台、构建开关、线程数和工作负载。
- 增量堆数据、进程工作集、生成峰值和卸载后的池保留属于不同统计口径。
