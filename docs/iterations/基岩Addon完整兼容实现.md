## 实施顺序与验收条件

以下各项均属于完整目标；完成单项不代表 Addon 已兼容。

1. **运行时基础**：调度取消和时序、独立回调引用及上下文清理、事件重入与取消、上下文隔离的模块和类型注册；通过真实 QuickJS 回归测试。
2. **包加载**：路径规范化、包依赖排序、版本与入口校验、BP/RP 栈、压缩包导入、错误传播；加载失败必须返回失败。
3. **脚本生命周期**：startup、世界就绪、restricted execution、scriptEvent 通信、生成器任务及看门狗。
4. **事件数据**：公共事件快照、对象包装、过滤、取消及可修改字段回写；接入真实服务端触发位置。
5. **脚本对象模型**：上下文内 Entity/Player 继承、稳定字符串 ID、世界/维度查询、生成/移除/伤害/射线/命令/音效/粒子接口。
6. **属性及持久化**：包作用域动态属性、声明式实体属性、延迟应用、实体与世界保存恢复、客户端同步。
7. **自定义组件**：按组件名称注册，通过 JSON 关联类型和 permutation，传递完整回调对象与参数并回写放置状态。
8. **行为包定义**：实体、物品、方块、配方、掉落、生成规则和函数加载，复用现有注册表、容器、战斗、寻路及刷怪设施。
9. **数据驱动实体**：组件组变更、事件动作、过滤器、计时器与感应器、驯服/骑乘/背包/投射物、JSON 配置 AI。
10. **Molang 与方块状态**：表达式、属性查询、traits、permutation、基岩/Java 状态语义转换。
11. **物品及容器 API**：耐久写回、附魔、冷却、lore、容器槽位与迁移、记分板读写。
12. **基岩命令**：event/scriptevent/titleraw、选择器、声音参数、函数和 RawMessage 语义。
13. **结构**：实体、双层方块、方块实体与自定义内容的完整还原。
14. **Java 呈现**：自定义内容协议投影、资源包转换与分发、几何/骨骼/动画、音效/粒子/字体/本地化、属性同步及 server-ui 表单适配。
15. **插件验收**：脚本导入与 startup、实体生成与初始化、驯服/跟随/坐下/拥抱、背包/墓碑、工作与战斗、祭坛/微波炉/雕像、符卡/御币、管理与皮肤界面、存档重启、多包隔离。
