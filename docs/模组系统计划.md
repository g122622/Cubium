#### 3.1 插件管理 ✅
- `plugin/` — ScriptPlugin（状态机）、ScriptPluginManager、ScriptPluginSource、ScriptPackPermissions、ScriptPackConfiguration、PluginExecutionGroup

#### 3.2 服务端集成 ✅
