# 世界与服务端领域重构

## 已确认的边界

- 采用代码中集中定义的 BlockSetType/WoodType；不增加数据包格式。
- 世界效果使用 LevelEventId，与 SoundEvents、GameEvent 分开。
- 拆分方块基础类型并按行为族整理目录，保留 Block 主继承体系。
- 区块生成阶段模型归服务端管线；共享生成类型按实际使用者归属。
- 月相归共享时间领域，消除重复时间规则；timeline 迁至 time/timeline。
- 清空 server/core 和对应命名空间，拆分移动/订阅、发送/连接/玩家退出职责。
- 不保留旧头文件、类型别名或兼容转发层；完成构建和本次涉及的小规模测试；不启动工作流或子代理。

## 实施顺序与验收

1. 拆分 StatePredicate、BlockProperties、偏移/乐器/渲染枚举；删除 VoxelShapes 的单位猜测入口。
   地图颜色在注册阶段绑定策略，状态缓存仍按各自状态求值，公共 Block 不引用原版快照。
2. 将模型、状态、基础类型、能力、标签、支撑、通用注册和原版注册分目录。
   门、活板门、栅栏门、容器、熔炉、炼药锅、告示牌等按行为族收拢；独占工具归使用者。
3. 定义原版方块族，覆盖铁/铜/石/黑石及十二种木材。
   门、活板门、按钮、压力板、栅栏门和告示牌显式绑定族；修正铜门交互及变种声音。
   使用现有 SoundEvents，移除旧整数音效方法；音效与模拟 GameEvent 分别派发。
4. 按本地 1.21.11 LevelEvent 校正完整枚举，清除过时值与重复编号，补齐 3014。
   世界、广播及测试入口接受强类型，只在编码/解码边界转换整数；审查原始整数调用。
5. 区块阶段模型迁至 server/world/chunk/base/pipeline，更新构建目标归属。
   共享噪声归数学模块，结构包围盒下沉服务端，拼图朝向与真菌类型归方块基础类型。
   密度函数接口和装饰阶段保留共享生成领域，禁止 common 反向依赖 server。
6. 月相、周期及亮度规则归 common/world/time，时间线、光照和天体调用统一复用。
   TimeManager 归 server/world/time，保留服务器时钟与实际维度环境求值边界。
7. 玩家管理归 player/lifecycle，运行数据归 player/runtime，模式服务归 player/gamemode。
   玩家移动归 player/movement；订阅与发送标记归已有区块同步组件。
   心跳归 network/session/keepalive，传送同步确认归 network/sync/player。
   出站投递、连接断开、玩家退出各归领域入口；移除钩子保证资源先释放、记录后删除。
   白名单/封禁归 access/admission，权限归 access/permission，通过准入门面暴露名单操作。
8. 更新 include、命名空间、CMake 清单、测试及目录链 README。
   静态核对旧路径/旧类已清除、所有新源文件进入正确目标、头文件可解析、编号唯一且与原版一致。
   行为测试覆盖门族规则、效果编号与载荷、退出清理、传送确认、区块订阅及月相边界。

## 验证约束

除静态审查、格式化和引用检查外，执行项目规定的构建命令，并按重构范围筛选少量测试。
