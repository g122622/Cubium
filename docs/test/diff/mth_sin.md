# 差分能力：`mth_sin`

> 由 `tests/diff/README.md` 拆分而来，记录该能力的实现要点、踩坑与验证结论。
> 跨能力共性规律见 [`_patterns.md`](./_patterns.md)。

第 101 个能力，33 个正弦/余弦用例全部一致。验证了 Cubium 的 `MathUtils::mthSin` / `mthCos`
表构造方式与原版逐位一致。

## 四个关键点

**1. 这是查表，不是 `Math.sin`。**

```java
private static final float[] SIN = Util.make(new float[65536], a -> {
    for (int i = 0; i < a.length; i++) {
        a[i] = (float) Math.sin(i / 10430.378350470453);
    }
});

public static float sin(double v) {
    return SIN[(int)((long)(v * 10430.378350470453) & 65535L)];
}
```

表的量化粒度是 `2π / 65536 ≈ 9.587e-5` 弧度。直接调 `std::sin` 会在绝大多数输入上与表项
相差 1 ulp 以上。

**2. 小于半个量化步长的输入被抹平为 0。**

| 单元 | `sin` |
|---|---|
| `0` | `0` |
| `0.00001` | **`0`** |
| `0.0001` | `9.58738019e-05` |
| `0.0002` | `0.000191747604` |

`0.00001 * 10430.378 = 0.1043`，强转 `long` 后是 `0`，取表项 `SIN[0] = 0`。**极小的非零
角度在查表实现下等于 0**，而 `std::sin(0.00001) = 1e-5` 不为零。

**3. 数学上应为零的点，查表保留 `Math.sin` 的残差。**

| 单元 | 结果 |
|---|---|
| `sin(π)` | **`1.22464685e-16`** |
| `tab\|32768` | **`1.22464685e-16`** |
| `cos(π)` | `-1` |
| `sin(π/2)` | `1` |
| `tab\|16384` / `tab\|49152` | `1` / `-1` |

`SIN[32768] = (float)Math.sin(32768 / 10430.378...) = (float)Math.sin(3.14159265...)`，
而 `Math.sin(π)` 在双精度下不是精确 0。表项把这个残差固化下来，`sin(π)` 因此**永远不等于
精确的 0**——任何 `sin(x) == 0` 的判定在 `x = π` 处都会失败。

峰值处（`tab|16384`）则精确为 1，因为 `Math.sin(π/2)` 的双精度结果转 `float` 后就是 1.0。

**4. `cos` 复用同一张表，索引加 16384。**

```java
public static float cos(double v) {
    return SIN[(int)((long)(v * 10430.378350470453 + 16384.0) & 65535L)];
}
```

65536 / 4 = 16384，即四分之一周期。这样 `cos` 与 `sin` 的量化误差分布完全一致，不会出现
「sin 对上了但 cos 没对上」的独立误差源。

## 关于 `std::sin` 与 Java `Math.sin` 的一致性

**本能力真正要验证的**是：Java 的 `Math.sin`（JDK 用 fdlibm）与 C 的 `std::sin`
（MSVC UCRT）在 `i / 10430.378350470453` 这些具体输入上是否逐位相同。若某个表项差
1 ulp，`sin(v)` 在该索引上就会分叉。

**结论：抽样的 14 个表项全部逐位相同。** Cubium 的 `MathUtils::mthSin` 用
`static_cast<f32>(std::sin(i / SIN_SCALE))` 构造表，与原版等价。

这不能证明整张 65536 项的表都一致（只抽了 14 个），但覆盖了各象限、峰值、表尾等关键位置。

## 未覆盖范围

- `Mth.COS_TAB`（`asin` 用的 257 项表，构造方式不同）
- `Mth.sqrt`（直接转 `std::sqrt`，无查表）
- 全表 65536 项逐一比对（可作为后续加强项）
