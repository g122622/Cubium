# 差分能力：`collide_sweep`

> 由 `tests/diff/README.md` 拆分而来，记录该能力的实现要点、踩坑与验证结论。
> 跨能力共性规律见 [`_patterns.md`](./_patterns.md)。

第 106 个能力，23 个碰撞扫描用例全部一致。实体碰撞的轴推进逻辑此前没有被比对过，
`entity_shape` 只覆盖了实体尺寸。

## 四个关键点

**1. Y 轴永远第一个处理，X/Z 的先后由位移决定。**

```java
private static final List<Axis> YXZ_AXIS_ORDER = List.of(Axis.Y, Axis.X, Axis.Z);
private static final List<Axis> YZX_AXIS_ORDER = List.of(Axis.Y, Axis.Z, Axis.X);

public static List<Axis> axisStepOrder(Vec3 delta) {
    return Math.abs(delta.x) < Math.abs(delta.z) ? YZX_AXIS_ORDER : YXZ_AXIS_ORDER;
}
```

| 单元 | 轴序 | 说明 |
|---|---|---|
| `axis(1, 0, 0)` | `yxz` | `\|x\| ≥ \|z\|` |
| `axis(0, 0, 1)` | `yzx` | `\|x\| < \|z\|` |
| `axis(0, 0, 0)` | `yxz` | 相等时走 YXZ（`<` 不是 `<=`） |
| `axis(-1, 0, 1)` | `yxz` | 用**绝对值**比较，`1 < 1` 为假 |
| `axis(0.5, 0, 1)` | `yzx` | `0.5 < 1` |

**主轴（位移分量大的那条）最后推进**，这样侧向位移不会提前把实体推离主轴路径。Y 永远第一，
因为跳跃/重力需要最先解算。

**2. 撞墙后另一轴仍独立推进。**

| 单元 | 位移 |
|---|---|
| `collide(1,0,1)`，X 方向有墙 | **`(0.4, 0, 1)`** |
| `collide(1,0,1)`，Z 方向有墙 | **`(1, 0, 0.4)`** |

这正是分轴解算的意义：**贴着墙可以沿墙滑动**，而不是被整体挡住。若把位移当作一个整体
矢量去求交，会得到 `(0,0,0)`——完全不同的手感。

**3. 间隙为 0 时完全不动。**

| 单元 | 位移 |
|---|---|
| 实体 `[0,0.6]`，墙从 `1.0` 开始 | **`(0.4, 0, 0)`** |
| 实体 `[0,0.6]`，墙从 `0.6` 开始 | **`(0, 0, 0)`** |

第二种情况实体紧贴墙面，`1e-7` 容差让「恰好贴合」判为碰撞，位移被压到 0。

**4. `|d| < 1e-7` 是严格小于。**

| 单元 | 位移 |
|---|---|
| `collide(0.0000001, 0, 0)` | **`(1e-07, 0, 0)`** |

位移恰好等于 `1e-7` 时**不被抹掉**。`1e-7` 容差同时出现在两处：
- 碰撞判定（`d2 >= -1e-7`）：让恰好贴合的面上沿不被判为碰撞
- 提前返回（`|d| < 1e-7`）：抹掉微小残余

两处都用固定绝对容差，**不随坐标量级缩放**。在远坐标（如 3000 万）处，`double` 的有效精度
已接近 `1e-9`，此时 `1e-7` 的容差相对于坐标量级仍然可用，但相对精度已明显下降。

## 实现说明

探针复刻了「单盒形状」的碰撞语义：对每个在另两轴上与运动盒重叠的碰撞盒，若其起始面在
`-1e-7` 容差内可达，则位移被压到「碰撞盒起始面 − 运动盒末尾面」，并**首次命中即返回**。

原版在 `VoxelShape` 上还做了 `findIndex` 的区间裁剪（只搜与运动盒相交的格子），这对单盒
形状是等价的，对多盒形状才影响性能与顺序。
