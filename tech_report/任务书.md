## 1.1 线程池设计

**对于游戏开发这种对延迟和吞吐量都有较高要求的场景，把CPU密集型和IO密集型任务全部丢进一个共享线程池，通常是不合理的，甚至可能引发严重问题。**

因此CPU密集型和IO密集型任务分离，不共享同一个线程池。

| 特性         | CPU密集型任务                        | IO密集型任务                   |
| ---------- | ------------------------------- | ------------------------- |
| **任务特点**   | 持续占用CPU进行计算                     | 大部分时间在等待外部响应（如文件读写、网络请求）。 |
| **对线程的需求** | 线程数 ≈ CPU核心数，能最大化利用率，避免上下文切换开销。 | 线程数可以远超核心数，让线程在等待时让出CPU。  |
| **核心矛盾**   | 希望线程**一直运行**，别切换。               | 线程会**主动阻塞**，交出控制权。        |

CPU密集型任务：区块生成、光照计算、区块网格生成（仅客户端）
IO密集型任务：区块的读取和保存
